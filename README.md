# Mohammad Mohseni Pour — Portfolio v2

Bilingual Persian / English responsive portfolio.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive layout, animations, and print styles
- `script.js` — language switcher, mobile menu, scroll effects, and print action

## Publish the update
1. Extract this ZIP.
2. Open `Mmohseni2113.github.io` on GitHub.
3. Replace `index.html`, `styles.css`, and `script.js` with these versions.
4. Keep the files in the repository root, not inside a folder.
5. Commit the changes. GitHub Pages should stay set to `main` and `/(root)`.

Private model/runtime details are intentionally not disclosed. Check company and product descriptions before public release.
