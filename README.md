# Mohammad Mohseni Pour — Personal Portfolio

A bilingual Persian/English static portfolio website.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive visual design and print stylesheet
- `script.js` — language switcher (FA/EN)

## Preview locally
Open `index.html` in a browser. Internet access is only needed for the Google Fonts import; the site otherwise runs as a static page.

## Publish free with GitHub Pages
1. Create a new public repository named `Mmohseni2113.github.io`.
2. Upload the contents of this folder to the repository root (not the containing folder).
3. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After deployment, the site will be available at `https://Mmohseni2113.github.io`.

## Important before publishing
- Confirm every project description and status.
- Add verified links to project repositories only after checking that no credentials, session files, API keys, or private data are exposed.
- Replace or remove any contact details you do not want public.
- Add a professional portrait only if desired.
- The browser Print button can be used to save a PDF. For a polished final CV PDF, review page breaks before sharing.
